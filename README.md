"Vriksh.Care" [Community Tree Plantation & Survival Tracking Portal]

Plantation drives often fail because trees are planted but never nurtured.We are building a web application that allows volunteers to geotag newly planted saplings, log watering schedules, and monitor survival rates with photo updates.
Gamified dashboard (earning badges for keeping trees alive), map integration layout, and simple image-upload workflows.
